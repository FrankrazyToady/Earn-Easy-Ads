# Earn Easy Ads

Earn Easy Ads is a modern Android app that allows users to earn money by watching ads. Users can track their earnings, withdraw via multiple payment methods, and engage with gamification features like streaks and daily goals.

## Features

- Watch ads and earn rewards (internal & network ads)
- Wallet to track earnings
- Withdraw earnings via M-Pesa, PayPal, or Crypto
- Daily goals, streaks, and badges
- Referral system for extra rewards
- Push notifications for high-paying ads
- Admin dashboard to upload internal ads
- Analytics tracking for ad views and clicks

## Tech Stack

- Language: Kotlin
- Architecture: Native Android
- Networking: Retrofit + Gson
- Storage: SharedPreferences
- Ads: Internal + AdMob/UnityAds (future)
- Notifications: PushNotificationService
